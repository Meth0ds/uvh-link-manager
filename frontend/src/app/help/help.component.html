Ayuda técnica de UVH

Guías concisas para publicar enlaces, verificar dominios e integrar la API y los webhooks sin rebajar las garantías de seguridad.

01

Publicar un enlace

  1. Crea el enlace como borrador y revisa el destino, el dominio y el alias.
  2. Define las reglas en orden de prioridad; el destino principal actúa como salida segura.
  3. Publica solo después de comprobar el estado, la caducidad y los límites de uso.

Las ediciones posteriores quedan asociadas al workspace y a su registro de actividad.

02

Verificar un dominio

  1. Añade en tu proveedor DNS el registro exacto que muestra el panel.
  2. Usa Comprobar ahora para una verificación manual o consulta la próxima revisión automática.
  3. No publiques hasta que DNS y TLS aparezcan saludables.

La propagación DNS y la emisión TLS no son instantáneas. El diagnóstico indica qué falta y cuándo se volverá a comprobar.

03

Consumir la API

Envía el token como Authorization: Bearer <token> y concede únicamente los ámbitos necesarios. Guarda el secreto fuera del código y rótalo si pudiera haberse expuesto.

  • Usa rutas bajo /api/v1.
  • Respeta Retry-After y aplica espera exponencial.
  • Trata cada respuesta como no confiable hasta validarla contra tu contrato.

04

Validar firmas de webhook

Lee el cuerpo HTTP sin modificar y calcula HMAC-SHA256 sobre <timestamp>.<rawBody>. Compara en tiempo constante el hexadecimal obtenido con v1.

UVH-Signature: t=<milisegundos>,v1=<hmac-hex>
  • Rechaza marcas de tiempo fuera de tu ventana de tolerancia.
  • Deduplica por identificador de evento: la entrega es al menos una vez.
  • Responde con éxito solo cuando el evento se haya persistido de forma duradera.
  • No registres el secreto, la cabecera completa ni cuerpos con datos sensibles.
