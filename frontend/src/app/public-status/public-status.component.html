Cómo leer esta páginaexpand_more

Mediciones, no promesas. Se muestra una instantánea del monitor externo, no una comprobación continua desde tu navegador. Usa «Actualizar estado» para consultar otra vez.

Sin señal no significa operativo. Si el feed falta, está caducado o no cumple el contrato, el resultado es desconocido. No publicamos versiones, direcciones internas ni topología.

Una página no demuestra independencia. La continuidad del monitor durante una caída de UVH debe verificarse en el despliegue. El diseño de esta pantalla no acredita esa prueba.
